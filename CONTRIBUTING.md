# Contributing

- Build: `make`. Test: `make test` (golden tests under `tests/golden/`, runner `tests/run.py`).
- A test is a directory with `input.zev` and one of `expected_output.txt` (run) or `expected_error.txt` (compile error).
  Extra `.zev`, `.c` and `.cpp` files in the directory are passed to the compiler; `args.txt` adds options
  (`{dir}` is the test directory, `{tmp}` a scratch directory).
- The standard library is Zevic code under `stdlib/`. `stdlib/Convert.zev` is generated by `tools/gen_convert.py`.
- Keep commits small: one change, one commit, tests in their own commit when that reads better.
- The language is described in `docs/spec/zevic-spec.md`. If the compiler and the spec disagree, fix one of them in the same change.
- Needs clang 15 or newer to build the generated LLVM IR (`apt install clang`, `winget install LLVM.LLVM`, `brew install llvm`).
